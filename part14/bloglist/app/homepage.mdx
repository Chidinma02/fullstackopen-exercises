# Welcome to BlogApp

A modern, full-stack blogging platform built with Next.js, Drizzle ORM, and React 19 as part of the Full Stack Open curriculum.

## Features

- **User Authentication**: Secure registration and login powered by NextAuth.js and bcrypt password hashing.
- **Blog Management**: Create, view, like, and filter blogs with seamless server-side validation.
- **Personal Reading Lists**: Track blogs to read, mark articles as read, and organize your study path.
- **Developer API**: Generate personal API access tokens to integrate programmatic workflows at `/api/me`.
